# rv32i-core-verif

A 5-stage pipelined RV32I CPU in SystemVerilog, verified against a Python golden model
using cocotb + Verilator (directed tests, constrained-random streams, scoreboard,
functional coverage).

> **Status:** work in progress. See [ROADMAP.md](ROADMAP.md) for milestones.
> Results will be added here only once they are measured, together with the command that produced them.
